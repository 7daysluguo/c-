# 计数算法 (Counting Algorithms)

本文档介绍常见的计数算法及其C++实现。

## 1. 计数排序 (Counting Sort)

计数排序是一个非比较型整数排序算法，其时间复杂度为O(n+k)，其中k是整数的范围。

### C++实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

void countingSort(std::vector<int>& arr) {
    if (arr.empty()) return;
    
    // 找到最大值和最小值
    int maxVal = *std::max_element(arr.begin(), arr.end());
    int minVal = *std::min_element(arr.begin(), arr.end());
    int range = maxVal - minVal + 1;
    
    // 创建计数数组
    std::vector<int> count(range, 0);
    std::vector<int> output(arr.size());
    
    // 统计每个元素出现的次数
    for (int i = 0; i < arr.size(); i++) {
        count[arr[i] - minVal]++;
    }
    
    // 累加计数数组
    for (int i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }
    
    // 构建输出数组
    for (int i = arr.size() - 1; i >= 0; i--) {
        output[count[arr[i] - minVal] - 1] = arr[i];
        count[arr[i] - minVal]--;
    }
    
    // 复制回原数组
    arr = output;
}
```

### 使用示例

```cpp
int main() {
    std::vector<int> arr = {4, 2, 2, 8, 3, 3, 1};
    
    std::cout << "排序前: ";
    for (int num : arr) std::cout << num << " ";
    std::cout << std::endl;
    
    countingSort(arr);
    
    std::cout << "排序后: ";
    for (int num : arr) std::cout << num << " ";
    std::cout << std::endl;
    
    return 0;
}
```

## 2. 元素频率统计

统计数组中每个元素出现的次数。

### C++实现

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>

std::unordered_map<int, int> countFrequency(const std::vector<int>& arr) {
    std::unordered_map<int, int> frequency;
    
    for (int num : arr) {
        frequency[num]++;
    }
    
    return frequency;
}

void printFrequency(const std::vector<int>& arr) {
    auto freq = countFrequency(arr);
    
    std::cout << "元素频率统计:" << std::endl;
    for (const auto& pair : freq) {
        std::cout << "元素 " << pair.first 
                  << " 出现 " << pair.second << " 次" << std::endl;
    }
}
```

## 3. 区间计数查询

使用前缀和数组快速查询区间内满足条件的元素个数。

### C++实现

```cpp
#include <iostream>
#include <vector>

class RangeCounter {
private:
    std::vector<int> prefixSum;
    
public:
    // 构建前缀和数组
    RangeCounter(const std::vector<int>& arr) {
        int n = arr.size();
        prefixSum.resize(n + 1, 0);
        
        for (int i = 0; i < n; i++) {
            prefixSum[i + 1] = prefixSum[i] + arr[i];
        }
    }
    
    // 查询区间[left, right]的和
    int rangeSum(int left, int right) {
        if (left < 0 || right >= prefixSum.size() - 1) {
            return -1; // 越界
        }
        return prefixSum[right + 1] - prefixSum[left];
    }
    
    // 查询区间[left, right]的平均值
    double rangeAverage(int left, int right) {
        int sum = rangeSum(left, right);
        return static_cast<double>(sum) / (right - left + 1);
    }
};
```

## 4. 快速计数特定值

在排序数组中快速计数特定值的出现次数。

### C++实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 使用二分查找统计有序数组中某个值的出现次数
int countOccurrences(const std::vector<int>& arr, int target) {
    // 找到第一个等于target的位置
    auto lower = std::lower_bound(arr.begin(), arr.end(), target);
    
    // 找到第一个大于target的位置
    auto upper = std::upper_bound(arr.begin(), arr.end(), target);
    
    return upper - lower;
}

// 使用二分查找统计范围内的元素个数
int countInRange(const std::vector<int>& arr, int left, int right) {
    auto lower = std::lower_bound(arr.begin(), arr.end(), left);
    auto upper = std::upper_bound(arr.begin(), arr.end(), right);
    
    return upper - lower;
}
```

## 5. 位计数 (Bit Counting)

统计整数的二进制表示中1的个数。

### C++实现

```cpp
#include <iostream>
#include <bitset>

// 方法1：使用位运算
int countBits1(int n) {
    int count = 0;
    while (n) {
        count += n & 1;
        n >>= 1;
    }
    return count;
}

// 方法2：Brian Kernighan算法
int countBits2(int n) {
    int count = 0;
    while (n) {
        n &= (n - 1); // 清除最右边的1
        count++;
    }
    return count;
}

// 方法3：使用内建函数
int countBits3(int n) {
    return __builtin_popcount(n);
}

// 方法4：使用bitset
int countBits4(int n) {
    return std::bitset<32>(n).count();
}
```

## 6. 逆序对计数

统计数组中逆序对的个数（使用归并排序）。

### C++实现

```cpp
#include <iostream>
#include <vector>

long long mergeAndCount(std::vector<int>& arr, int left, int mid, int right) {
    std::vector<int> leftArr(arr.begin() + left, arr.begin() + mid + 1);
    std::vector<int> rightArr(arr.begin() + mid + 1, arr.begin() + right + 1);
    
    int i = 0, j = 0, k = left;
    long long invCount = 0;
    
    while (i < leftArr.size() && j < rightArr.size()) {
        if (leftArr[i] <= rightArr[j]) {
            arr[k++] = leftArr[i++];
        } else {
            arr[k++] = rightArr[j++];
            invCount += (leftArr.size() - i);
        }
    }
    
    while (i < leftArr.size()) {
        arr[k++] = leftArr[i++];
    }
    
    while (j < rightArr.size()) {
        arr[k++] = rightArr[j++];
    }
    
    return invCount;
}

long long mergeSortAndCount(std::vector<int>& arr, int left, int right) {
    long long invCount = 0;
    
    if (left < right) {
        int mid = left + (right - left) / 2;
        
        invCount += mergeSortAndCount(arr, left, mid);
        invCount += mergeSortAndCount(arr, mid + 1, right);
        invCount += mergeAndCount(arr, left, mid, right);
    }
    
    return invCount;
}

long long countInversions(std::vector<int> arr) {
    return mergeSortAndCount(arr, 0, arr.size() - 1);
}
```

## 复杂度总结

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 计数排序 | O(n+k) | O(n+k) | 整数范围较小 |
| 频率统计 | O(n) | O(n) | 通用统计 |
| 区间计数 | O(n)预处理 + O(1)查询 | O(n) | 多次区间查询 |
| 二分计数 | O(log n) | O(1) | 有序数组 |
| 位计数 | O(log n) | O(1) | 位运算 |
| 逆序对计数 | O(n log n) | O(n) | 数组排序 |

## 总结

计数算法在数据处理和统计分析中非常重要，根据具体场景选择合适的算法可以大大提高效率。
